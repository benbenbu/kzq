16×9字模转换工具

将32字节16×9字模数据转换为72字节输出

转换规则说明：

  1. 输入为32字节数组，代表16行×2字节的字模数据
  2. 每2个字节处理一次：取第一个字节的8位 + 第二个字节的最高位（共9位）
  3. 第二个字节的低7位舍去不管
  4. 从高到低处理这9位：1 转换为半字节 F，0 转换为半字节 0
  5. 9位转换为36位（18个半字节），相邻两个半字节组成一个字节
  6. 每行输出4.5字节，16行总共输出72字节

示例：

输入: 0x1E, 0x00 （第3行数据）

0x1E = 00011110，第2字节最高位 = 0

9位数据：000111100

转换为36位：0000 0000 0000 1111 1111 0000 0000 0000 0000

组合成18个半字节：00 00 0F F0 00（4.5字节）

支持的输入格式：

格式1 - 连续32字节：

0x00,0x00,0x00,0x00,0x00,0x00,0x1E,0x00,0x33,0x00,0x61,0x00,0x60,0x00,0x60,0x00, 0x60,0x00,0x60,0x00,0x61,0x00,0x33,0x00,0x1E,0x00,0x00,0x00,0x00,0x00,0x00,0x00

格式2 - 16行×2字节：

0x00, 0x00
0x00, 0x00
0x1E, 0x00
...
